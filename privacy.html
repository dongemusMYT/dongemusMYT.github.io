Privacy Policy

Dissociate State Analytics. Last updated November 25, 2026.

Dissociate State Analytics is a private tool used only by the owner of the Dissociate State YouTube channel and the owner's other YouTube channels. It is not offered to the public.

What it accesses

With the owner's sign-in, it reads the owner's own channels' YouTube data and YouTube Analytics (read-only): video lists, view counts and similar statistics. It cannot upload, change or delete anything.

How the data is used

The data is used only to plan and schedule the owner's own videos. It is kept on the owner's own computers. It is not sold, shared with anyone else or used for advertising.

Other people's data

The tool does not collect any data about viewers or anyone other than the owner.

Removing access

Access can be removed at any time at myaccount.google.com/permissions.

Use of information received from Google APIs follows the Google API Services User Data Policy, including its Limited Use requirements.
